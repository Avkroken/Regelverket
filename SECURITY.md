# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues.

Use the repository **Security** tab and **Report a vulnerability** flow when available. If private vulnerability reporting is unavailable, contact `dev@denied.se`.

Include a concise description, reproduction steps when practical, potential impact, and relevant evidence. Do not include credentials, tokens, private keys, personal data, or other secrets in public issues or pull requests.

## Scope

Regelverket is a retired transition repository. Security concerns here are limited to the remaining repository workflows, configuration, and transition artifacts. No new product functionality should be introduced.

Only the current `main` branch is supported.
